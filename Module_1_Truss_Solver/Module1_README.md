# Module 1 — 2D Truss Solver

A MATLAB-based finite element solver for two-dimensional truss structures.

This module implements the complete finite element analysis workflow for 2D truss structures, including CAD-based geometry import, node and element processing, global stiffness matrix assembly, boundary conditions, load definition, solution, and structural post-processing.

## Features

The solver provides:

- DXF-based CAD geometry import
- Automatic node extraction and numbering
- Element connectivity generation
- Node merging and element deduplication
- Global stiffness matrix assembly
- Sparse matrix storage
- Boundary condition application
- Nodal load definition
- Singular-system detection
- Nodal displacement solution
- Element strain and stress calculation
- Element axial force calculation
- Support reaction calculation
- Deformed-shape visualization
- Color-mapped result visualization
- Numerical result tables

## Formulation

The solver uses standard 2D truss elements with two translational degrees of freedom per node.

Element stiffness matrices are assembled into a global sparse stiffness matrix using the direct stiffness method. After applying the specified boundary conditions, the resulting system is solved for the unknown nodal displacements.

Element strains, stresses, axial forces, and support reactions are then calculated from the obtained displacement field.

The current formulation assumes:

- Linear elastic material behavior
- Small deformations
- Axial deformation only
- Constant cross-sectional area for each truss member

## Workflow

The analysis workflow is:

```text
CAD Geometry
     ↓
DXF Import
     ↓
Node Processing
     ↓
Geometry Verification
     ↓
Global Stiffness Matrix
     ↓
Boundary Conditions + Loads
     ↓
BC / Load Verification
     ↓
FE Solution
     ↓
Post-Processing
     ↓
Results
```

The solver provides visual verification at important stages of the analysis.

### Geometry Verification

Element and node numbering are displayed so that the imported geometry and generated connectivity can be checked before solving the model.

### Boundary Condition and Load Verification

Supports and applied force vectors are displayed on the structure. This allows the user to check the analysis setup before interpreting the results.

## CAD / DXF Geometry Import

The solver imports truss geometry from DXF files.

Currently supported DXF entities are:

- `LINE`
- `POLYLINE`

`LWPOLYLINE` entities are currently not supported.

The current implementation requires:

- The truss structure to be drawn as a wireframe consisting of straight line segments connecting the truss nodes
- The geometry to be defined in the global XY plane
- Geometry to be defined in millimeters

The DXF import functionality has been tested using geometry exported from Autodesk Inventor and SolidWorks. DXF files generated by other CAD systems are expected to work when the truss geometry is exported using compatible `LINE` or `POLYLINE` entities and follows the requirements above.

The DXF file is specified directly in the main script.

## Limitations

The current version has the following limitations:

- Only 2D truss structures are supported.
- The geometry must lie in the global XY plane in the CAD drawing.
- CAD geometry is expected to use millimeter units.
- Only DXF geometry import is supported.
- DXF exports with `LWPOLYLINE` entities are currently not supported.
- Truss members are assumed to carry axial loads only.
- Loads are applied at nodes.
- Distributed loads are not supported.
- Linear elastic material behavior is assumed.
- Small-deformation analysis is assumed.
- Material nonlinearities are not considered.
- Geometric nonlinearities are not considered.
- Each truss member is assumed to have a constant cross-sectional area.

## Requirements

- MATLAB
- A CAD software capable of exporting the truss geometry as a DXF file using supported entities (`LINE` or `POLYLINE`)

No external MATLAB toolbox is required for the core 2D truss solver.

## How to Run

1. Clone or download the repository.
2. Open MATLAB and set the repository directory as the current folder.
3. Add the `src` directory to the MATLAB path.
4. Open the main script in the `src` directory.
5. Specify the DXF geometry file and model properties in the main script.
6. Run the main script.
7. Verify the imported geometry using the element and node numbering plots.
8. Follow the Command Window prompts to define boundary conditions and applied loads.
9. Verify the boundary conditions and applied loads using the verification plot.
10. Review the generated result plots and numerical tables displayed in the Command Window.

For a complete worked example, see:

`Examples_and_Validation/Warren_Truss/`
