# Module 1 - 2D Truss Solver: Implementation

## 1. Overview

Brief explanation of what the module does.

## 2. CAD Geometry Import

DXF files are imported using `DXF_parser_truss.m`.

Supported DXF entities:
- LINE
- POLYLINE

The following requirements apply to the imported geometry:

- Truss structure to be drawn as wireframe consisting of straight line segments connecting the truss nodes.
- The truss must be defined in the global XY plane.
- The current implementation assumes that the CAD geometry is defined in millimeters.
- `LWPOLYLINE` entities are not currently supported.

The DXF import functionality has been tested using geometry exported from Autodesk Inventor and SolidWorks. DXF files generated by other CAD systems are expected to work when their truss geometry is exported using compatible `LINE` or `POLYLINE` entities and follows the requirements above.

The user must make sure to not export dashed annotation lines as a part of the truss structure.

The imported geometry is converted into a cell array containing
the start and end coordinates of each truss member. Each cell 
contains a member's coordinates in the following matrix format:

$$\begin{bmatrix} x_1 & x_2 \\
y_1 & y_2 \\ 
z_1 & z_2 \end{bmatrix} $$

It should be noted that even though the solver is 2D, the $z$ coordinates 
are still saved since the DXF format supports it.

## 3. Node Processing

For node numbering and connectivity `Node_numbering_and_connectivity.m` 
function is used. This function processes the truss member coordinates 
stored in the cell array, identifies repeated nodes, assigns unique node 
numbers, and determines the connectivity of each truss member.

Repeated nodes are merged and numbered using MATLAB's built-in `unique` function.
The resulting node numbers corresponding to each coordinate pair are stored in 
the third row of the truss member array. Since the $z$-values are unused and 
set to zero for 2D analysis, this row is utilized to store the node indices instead.


## 4. Geometry Verification

Before requesting any user-defined boundary conditions or loads, the solver generates 
verification plots showing the imported truss geometry together with element and node 
numbering. 

These plots allow the user to visually verify that the CAD geometry, node 
merging, element connectivity, and numbering have been interpreted correctly.

### Node Number Placement

Node numbers are automatically positioned around each node based on
the local geometry. The directions of connected truss members are
considered when selecting a suitable label location, reducing overlap
between node numbers and the truss geometry.

### Element Number Placement

Element numbers are positioned near the midpoint of each truss member.
The labels are offset in a direction perpendicular to the member,
preventing the element numbers from overlapping the truss member lines.

The global stiffness matrix is constructed automatically after this
geometry-processing stage and does not require additional user input.

## 5. Global Stiffness Matrix

The global stiffness matrix is constructed automatically from the
processed truss geometry.

For each truss member, the implementation calculates its:

- Length
- Direction cosines
- Element stiffness matrix

The element stiffness matrices are then assembled into the global
stiffness matrix according to the corresponding node connectivity
and degrees of freedom.

The global stiffness matrix is stored as a MATLAB sparse matrix to
reduce memory usage and improve efficiency for structures containing
many degrees of freedom.

The material Young's modulus and member cross-sectional area are
currently defined directly in the main script.

## 6. Boundary Conditions and Load Application

Boundary conditions and external loads are defined by the user
through the Command Window.

The user specifies the nodes associated with:

- Fixed supports
- Roller supports
- Applied forces

For applied forces, the user also provides the corresponding global
$x$- and $y$-components.

The specified boundary conditions are applied to the global stiffness
matrix and force vector. The resulting reduced system is checked for
rank deficiency before solving.

A rank-deficient reduced stiffness matrix indicates that the system
is singular and that a unique displacement solution cannot be obtained
under the specified boundary conditions.

Once the system is confirmed to be solvable, the unknown nodal
displacements are calculated from the reduced finite element system.

## 7. Boundary Condition and Load Verification

After the boundary conditions and external loads have been defined,
the solver generates a verification plot showing the applied supports
and forces on the truss geometry.

The plot includes graphical representations of:

- Fixed supports
- Roller supports
- Applied force vectors

This allows the user to visually confirm that the selected support
locations, support types, force locations, and force directions have
been interpreted correctly.


## 8. Post-Processing

After the displacement solution is obtained, the solver performs
element-level and structural post-processing.

The calculated results include:

- Nodal displacements
- Element strain
- Element stress
- Element axial force
- Support reactions

The element results are calculated from the solved nodal
displacements and the corresponding element properties and geometry.

The deformed truss geometry is also generated using the calculated
nodal displacements.

A displacement-based color mapping is applied to the deformed shape
to visualize the variation of displacement throughout the structure.

Additional color-mapped plots are generated for quantities such as
element axial force and stress.

## 9. Output

The final numerical results are displayed in the MATLAB Command Window
using MATLAB table objects.

The output is divided into separate tables for:

- Element axial forces
- Nodal displacements
- Support reactions

The element table contains the corresponding element number and
calculated axial force.

The nodal displacement table contains the displacement components
associated with each node.

The support reaction table contains the calculated reaction
components at constrained nodes.

The numerical output is formatted to a suitable number of significant
figures to improve readability while retaining sufficient numerical
precision.

## 10. Program Structure

The main script controls the overall analysis workflow and calls the
individual functions responsible for each stage.

The current implementation is organized into the following main
functions:

| Function                           | Purpose                                                                                |
| ---------------------------------- | -------------------------------------------------------------------------------------- |
| `DXF_parser_truss`                 | Imports truss geometry from a DXF file  |                          |
| `Node_numbering_and_connectivity`  | Identifies unique nodes, assigns node numbers, and establishes connectivity            |
| `plot_truss`                       | Generates geometry, element numbering, and node numbering plots |
| `Stiffness_matrix_constructor`     | Constructs and assembles the global stiffness matrix|
| `Boundary_conditions_and_solution` | Defines boundary conditions and loads, checks the system, and solves for displacements |
|`Boundary_condition_visualization`|Generates geometry with the applied boundary conditions and loads for visual confirmation|
| `Post_processing`                  | Calculates element results and support reactions and generates result visualizations   |

## 11. Analysis Workflow

The complete analysis workflow can be summarized as:

1. Import CAD geometry from a DXF file.
2. Extract and process the truss member coordinates.
3. Merge coincident nodes and establish node numbering and connectivity.
4. Generate geometry verification plots.
5. Automatically construct the global stiffness matrix.
6. Request boundary conditions and external loads from the user.
7. Check the resulting system for singularity.
8. Solve for the unknown nodal displacements.
9. Generate a boundary-condition and applied-load verification plot.
10. Calculate element strains, stresses, axial forces, and support reactions.
11. Generate deformed-shape and color-mapped result plots.
12. Display the numerical results in MATLAB tables.
